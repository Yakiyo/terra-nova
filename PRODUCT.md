# TerraNova

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

NASA Space Apps judges and people exploring terrestrial analogs for lunar and Martian sites. The user confirmed that demonstrations and repeated scientific use should be balanced.

## Product Purpose

Choose a planetary target, discover similar Earth locations, inspect the evidence, and explore local terrain.

## Capabilities and Constraints

Existing static JavaScript frontend and FastAPI backend. Offline-first with self-hosted assets. Scientific calculations belong in src/compute; the frontend renders API results. Preserve sources, dataset identifiers, custom profiles, ranking controls, validation, exports, map tools and terrain exploration.

## Brand Commitments

TerraNova name, temporary logo, NASA-inspired red, blue and white. The user requested the cinematic storytelling of Omega ClearSpace and Lenis scrolling. Maintain a consistent system across all pages. Sites must not be used.

## Evidence on Hand

data/targets.json, data/normalization.json, API responses, local planetary imagery in web/assets, vendored fonts and icon sprite. No final brand mark supplied.

## Product Principles

- Evidence stays accessible beside visual explanations.
- Discovery leads naturally into inspection.
- Cached data and unavailable data must remain distinguishable.
- Motion supports navigation and respects reduced-motion preferences.
